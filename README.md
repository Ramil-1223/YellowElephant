## YellowElephant: CLI for bases 1C & Postgres 🚀
Инструмент для автоматизации управления базами данных 1С:Предприятие в клиент-серверном режиме. Позволяет создавать и удалять информационные базы через удобный терминальный интерфейс, а также делать резервные копии.

## 🛠 Технологический стек 

## Client (CLI):

* Python 3.12+
* [questionary](https://github.com/tmbo/questionary) — интерактивные опросы в терминале.
* [rich](https://github.com/Textualize/rich) — красивые таблицы, прогресс-бары и логирование.
* [httpx](https://github.com/encode/httpx) — современные асинхронные HTTP-запросы к API.

## Server (Backend):

* [FastAPI](https://github.com/fastapi/fastapi) — высокопроизводительный API для взаимодействия с сервером 1С.
* [Uvicorn](https://github.com/Kludex/uvicorn) — ASGI сервер.
* [python-dotenv](https://github.com/theskumar/python-dotenv) — управление конфигурацией через переменные окружения.

## 📦 Установка и запуск через Docker
Приложение полностью контейнеризировано. Процесс сборки автоматизирован и включает в себя установку платформы 1С.

## Особенности Docker-сборки:
* Автоматизация ИТС: Bash-скрипт имитирует авторизацию на портале ИТС для загрузки дистрибутивов.
* Auto-install: Использование утилиты expect для автоматического прохождения инсталлятора 1С внутри контейнера.
* Security: Секреты (логин/пароль ИТС) передаются через механизмы Docker Compose Secrets, не попадая в слои образа.

## Быстрый старт:

   1. Клонируйте репозиторий:
	   - git clone https://github.com/Ramil-1223/YellowElephant
	   - cd YellowElephant/server
   
   2. Настройте окружение:
      - Создайте файл .env в котором хранятся данные от кластера 1С и СУБД postgres в корне проекта.
      - Создайте директорию secrets/ и поместите туда три файла с данными от портала релизов ИТС: username, pass и 1C_version.
   3. Запустите сборку и развертывание:
      - docker compose up -d --build
   
## ⚙️ Управление через Systemd
Имеется возможность управления CLI приложением как системной службы. Пример unit-файла в директории проекта systemd.
P.S. Необходимо создать пользователя и базу в СУБД postgres под которым будет работать приложение и назначить соответствующие права на директории, например на директории куда выполняется запись логов и резервное копирование.
## Настройка systemd:

1. Создайте символьную ссылку:
```
ln -s /YellowElephant/server/systemd/yellow_elephant.service /etc/systemd/system/yellow_elephant.service
```
2. Активируйте и запустите службу
```
systemctl enable --now yellow_elephant.service
```

## 🖥 Использование CLI
Запустите серверную часть на удаленном сервере. После запуска серверной части вы можете использовать CLI для управления базами, для этого запустите клиентскую часть, перед запуском настройте виртуальное окружение:
```
cd YellowElephant/client
python -m venv .venv
source .venv/bin/activate (Если Windows: .venv\Scripts\activate)
pip install -r requirements.txt
python main.py
```
